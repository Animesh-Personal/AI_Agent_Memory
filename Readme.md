# AI Agent Memory

This project demonstrates a LangChain/LangGraph agent that uses tool calling and conversation memory. It is built around a weather assistant that can answer location-aware questions and persist conversation state across sessions using different checkpoint backends.

## What this project includes

- OpenAI-backed LLM configuration using `langchain-openai`
- A simple tool-calling weather agent with mock tools
- In-memory conversation memory with `InMemorySaver`
- Persistent memory using SQLite (`SqliteSaver`)
- Persistent memory using PostgreSQL (`PostgresSaver`)
- A reusable helper for invoking the agent with a `thread_id`

## Project structure

- `in_memory_thread_demo.py` – demonstrates multiple conversations using separate thread IDs.
- `interactive_in_memory_chat.py` – interactive chat with in-memory conversation tracking
- `interactive_sqlite_checkpoint_chat.py` – interactive chat with SQLite-backed checkpoint memory
- `interactive_postgres_checkpoint_chat.py` – interactive chat with PostgreSQL-backed checkpoint memory
- `config/model_config.py` – loads the OpenAI environment variables
- `prompts/system_prompt.txt` – system instructions for the weather assistant
- `tools/tools_mock.py` – mock tools used by the agent
- `utils/agent_utils.py` – wrapper for invoking the agent with a thread ID
- `checkpoints.db` – SQLite checkpoint database generated by the SQLite demo

## Environment setup

This project expects the following environment variables to be defined in a `.env` file:

```env
OPENAI_API_KEY=your_key_here
OPENAI_API_BASE_URL=https://your-openai-endpoint/v1
OPENAI_MODEL_NAME=gpt-4o-mini
SUPABASE_DB_URI=postgresql://user:password@host:5432/postgres
```

The PostgreSQL value is only required if you want to run the Postgres checkpoint example.

## Local setup

In PowerShell, create and activate a virtual environment:

```powershell
py -3.11 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Running the examples

Run the in-memory chat demo:

```powershell
python interactive_in_memory_chat.py
```

Run the SQLite checkpoint demo:

```powershell
python interactive_sqlite_checkpoint_chat.py
```

Run the PostgreSQL checkpoint demo:

```powershell
python interactive_postgres_checkpoint_chat.py
```

## Example interactions

The agent is configured to behave as a weather assistant:

- If the user asks for weather in a city, it calls `get_weather(city)` directly.
- If the user asks for weather without naming a city, it first calls `get_location()` and then `get_weather(location)`.

Example prompts:

- `What is the weather in Paris?`
- `What is the weather like today?`

## Notes

- The project uses a mock weather tool and mock location lookup rather than a real weather API.
- The SQLite memory demo persists conversation state in `checkpoints.db`.
- The PostgreSQL demo persists conversation state in a configured Supabase/Postgres database.
- The agent uses `thread_id` to keep conversations separated while still preserving context within the same thread.
